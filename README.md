# huli CLI

`huli` is a command-line client for the Huli Public FHIR R4 + R5 API.

## Install

```bash
brew install hulilabs/tools/huli-cli
```

The installed binary is named `huli` (not `huli-cli`).

## Release artifacts

Each release attaches binaries for macOS (arm64/amd64) and Linux
(amd64/arm64); a Windows amd64 build is available as a zip archive.

## Documentation

Full usage documentation: https://developers.huli.ai/v1/cli/

## About this repository

This repository contains release artifacts only — no source code. For
issues, questions, or support, please refer to the documentation site
above.
